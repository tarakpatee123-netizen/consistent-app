# CONSISTENT — Personal Focus

Mobile-first offline web app for building study consistency.

## Included
- 25-minute minimum-day system
- 25/50/90-minute focus timer
- one active task at a time
- finish-before-new-task rule
- never-miss-twice streak tracking
- daily focus minutes and sessions
- 14-day progress history
- local device storage
- installable as a home-screen app (PWA)

## Run on a computer
Serve this folder with any local web server, then open it in a browser.

Example:

```bash
python -m http.server 8080
```

Open `http://localhost:8080`.

## Put it on an Android/iPhone
Host this folder on a HTTPS web host (for example GitHub Pages or another static host), open the URL on your phone, then use the browser's **Add to Home Screen / Install App** option.
